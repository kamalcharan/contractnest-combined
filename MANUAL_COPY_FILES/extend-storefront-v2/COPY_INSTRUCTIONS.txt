WHAT IT IS
  A storefront = one or more PUBLISHED packages (template families) with a
  card style and an FAQ. Website / WhatsApp are ways to share it, not rows.
    · /extend            product-led page: pitch when no channel is on;
                         storefront rows (chips, counters, actions), New
                         storefront (multi-pick), configurator (Show as ·
                         Button text · Colour: brand + 5 presets + any ·
                         Shape · A click opens · snippet · live preview ·
                         Copy link · Mail block · QR · For developers ·
                         FAQ editor · rename · pause), VaNi row/counterfactual
    · /p/:key            public package page (catalog when >1 package)
    · /buy/:key          public checkout with OTP (SMS via MSG91), then the
                         existing /contracts/review?cnak&secret flow

    · public/embed.js v2 data-view / data-label / data-color / data-shape /
                         data-mode; ContractNest.open() / .mount()
  WhatsApp = share via wa.me only (mock; owner: more to come). VaNi chat on
  the storefront and Leads are the next batches.
