Follows vani-tenant-flag (step 1). Owner: "tenant-context API is the starting
point, from there enhance automation rules, then stitch the rest on."

Decisions taken (left open in the review; say if you want them different):
  · The payment ladder FOLDS INTO the existing "Payment reminders" card —
    one card = the whole payment schedule (before-due email + after-due rungs).
  · Rungs are stored as THREE integer arrays — email / WhatsApp / call-task
    days after due. Presets (0/3/7 · Monthly · None) are UI sugar over them.
  · Group-session rule text + defaults corrected to what the engine really
    does (3d + 1d; absentee 3d out; no-show +2h) and say plainly that only
    the on/off switch is honoured today.
  · Rules stay EDITABLE whether VaNi is on or off (they are the tenant's own
    instructions; the API never gated editing). The runtime gate comes with
    the engine stitch.

Submodules affected: contractnest-ui, contractnest-api, contractnest-edge
(migration ALREADY APPLIED LIVE — source of record, do not re-run).
