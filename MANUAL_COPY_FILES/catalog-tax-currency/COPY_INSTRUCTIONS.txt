Owner's 8 points before onboarding-payments testing: seeding ignored tax
(/settings/tax-settings); billing therefore had no tax; VaNi Seeding ignored
tax; are all variants inserted; signia "only HVAC"; every KT currency seeded;
variant switch did nothing; "preview" banner had no preview.

Owner decisions: tax master (t_tax_settings / t_tax_rates) is NOT changed —
which taxes a new item carries is chosen WHERE it is seeded; separate onboarding
Tax screen (not folded into "Your business"); no prefilled rates — the user
creates them; currency lives on the Business Profile (default INR); other
currencies are added per item in Catalog Studio; clean-up for test tenants only.

Submodules: contractnest-ui, contractnest-api, contractnest-edge
COPY ORDER: onboarding-team-payments → vani-onboarding-cleanup →
            integrations-upi-qr → THIS.
  (App.tsx, journey.ts, ServiceableStep.tsx, contractComposerService.ts are
   supersets of those batches' copies.)

─── WHAT WAS WRONG ──────────────────────────────────
1. Seeding put a flat tax_rate on blocks (an invented 18% when nothing was set
   up) and EMPTY tax lines on the price records. The contract wizard reads the
   price records → every seeded block billed 0% tax. VaNi's composer read the
   flat 18% → the same block priced differently by the two.
2. Every KT currency was copied (signia: INR + EUR on 62 blocks, + USD).
3. Onboarding pricing review saved only base_price, one environment; the
   wizard reads the price line → the reviewed price never reached a contract.
4. VaNi Seeding: KT-ready items showed nothing until a hidden popup (8 rows);
   the variant switch couldn't change anything (all services carry all sizes,
   prices ignored the size); and the page — like pricing review — loaded only
   the first 100 blocks (the API caps a page at 100), so a second seeded
   equipment would vanish. signia shows only HVAC because HVAC is the only
   equipment it seeded — not a bug.
5. Variants: yes, all active variants are seeded — as prices INSIDE one
   service block (one service per job, each size its own price). Kept.
