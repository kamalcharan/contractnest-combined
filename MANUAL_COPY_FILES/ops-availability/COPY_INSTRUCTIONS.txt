─── WHAT IS LIVE (024) ─────────────────────────────
 Tenant defaults on the EXISTING cadence settings (which already held
 weekly_holidays + marked holidays): work_start 09:00, work_end 18:00,
 default_visit_minutes 60. get_tenant_cadence_settings returns them;
 upsert_tenant_working_hours(tenant, start, end, minutes) sets them.
 Per user: t_user_availability (work_start/work_end/weekly_off, NULL =
 the tenant's) and t_user_leave (date, part full|am|pm, label). RPCs
 get_user_availability · set_user_availability · add_user_leave ·
 remove_user_leave · get_team_availability. jtd_effective_hours(tenant,
 user) is the one place that decides which hours apply.
 jtd_visit_minutes(event): the contract block's config.duration
 (value + unit → minutes) else the tenant default. Fact: no block carries
 a duration today (0 of 5,425 catalog, 0 of 1,038 contract blocks), so
 every visit is the tenant default until blocks are filled in.
 jtd_slot_check(tenant, user, start, minutes, exclude_event) → [] or
 [{kind, detail, event_id?}] with kinds weekly_off · holiday · leave ·
 outside_hours · overlap. Overlaps are only against services that HAVE a
 timed slot (event rows carry their creation clock time, never a real
 time) so nothing false fires on unslotted services.
 Warnings: jtd_schedule_visit, jtd_confirm_visit_slot and jtd_assign_visit
 return `warnings` (the check for the technician). Appointment items carry
 duration_minutes (new ones at add; 168 existing back-filled).
 Board: every visit row's `visit` carries duration_minutes and, when the
 slot clashes, `clashes`. Plan counts gain `clashes`. "Plan this day" now
 starts from the organisation's work_start, steps by the default visit
 length per technician, refuses a tenant day off (`day_off`), and each
 placement carries its warnings (`warned_count`).

─── UI ─────────────────────────────────────────────

   takes N min", Save (own dirty state, own toast).
 /settings/users/:id → Overview gains "Working hours & leave": the hours
   that apply (their own / the organisation's), a "Their own hours" switch
   with time inputs and weekday chips (highlighted = off), Save; leave list
   with add (date, full/morning/afternoon, label) and remove. Toasts via
   the page's VaNi toast; spinners on load and on each save.
 Ops board + Plan tab: a red "⚠ outside hours / day off / holiday / on
   leave / overlaps (+N)" pill next to the kind pill on a service card,
   reasons on hover. Schedule / Confirm slot / Assign toasts append the
   warnings ("… · ⚠ overlaps AC servicing · CN-1010 at 14:00").
 Plan tab: "N clashes" in the day sentence and a red pill; Status select
   gains "Clashes".
