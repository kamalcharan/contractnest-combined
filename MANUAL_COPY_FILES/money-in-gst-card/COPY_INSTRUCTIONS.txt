Owner report: "/money-in is not showing GST — we have already built the
GST screen which can be navigated from here."

Submodules affected: contractnest-ui ONLY. No API/edge/RPC/DB change.

─── WHAT WAS ACTUALLY HAPPENING ─────────────────────

The GST card (GstMonthCard) has been on Money In (and To Pay) all along and
opens /taxes. It deliberately rendered NOTHING when the tenant's Tax
Settings display_mode is 'no_tax' — and BBB is 'no_tax' (t_tax_settings,
set 14 Aug; all 53 invoices carry ₹0 GST; no GSTIN on file). The data side
is healthy: get_tenant_tax_summary_v2 returns cleanly for BBB. So the card
was hidden by design, and that design left users wondering where GST went.

Also found: the "Tax settings" button on /taxes navigated to '/tax-settings',
which is not a route. The only route is '/settings/tax-settings' (nested
under /settings). Dead link — fixed in the same pass.
