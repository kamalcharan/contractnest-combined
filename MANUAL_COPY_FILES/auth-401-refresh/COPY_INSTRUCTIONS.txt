AUTH 401 / TOKEN-REFRESH FIX — "logged off after creating contract"
Branch folder: auth-401-refresh (2026-08-01)
Submodules affected: contractnest-ui ONLY (no API/edge/DB changes —
the refresh endpoint POST /api/auth/refresh-token already existed
end-to-end and was simply never called by the UI)
═══════════════════════════════════════════════════════════════════

ROOT CAUSE (recap)
──────────────────
1. Supabase access token expires (~1h); login stored refresh_token but
   NOTHING ever used it.
2. api.ts's 401 handler silently wiped auth storage — no logout, no
   redirect. The app kept working on axios's in-memory Authorization
   header (a zombie session).
3. The zombie died at the next HARD reload — which in the express flow
   is PlanStep → /ops/cockpit, i.e. immediately after creating the
   first contract. Hence "after creating contract, system logged off".

WHAT CHANGED
────────────
contractnest-ui/src/services/api.ts
  • New: single-flight refreshAuthToken() → POST /api/auth/refresh-token
    (bare axios, no interceptors), stores the rotated token pair in
    whichever storage held it (localStorage w/ remember-me, else
    sessionStorage), updates axios defaults.
  • 401 handling rewritten: non-credential endpoints get ONE refresh +
    retry (guarded by _authRetry so a request can never loop).
    /api/auth/user IS refreshable now — so a hard reload with an
    expired access token recovers instead of logging out.
    Credential endpoints (login, refresh-token, register, signout,
    reset/verify-password) are excluded — a 401 there is a real failure.
  • Only when refresh itself fails: storage cleared, axios header
    dropped, and a 'cn:auth-expired' event dispatched (skipped if
    already on a public auth page).
  • SESSION_CONFLICT 401 branch untouched.

contractnest-ui/src/context/AuthContext.tsx
  • New effect: listens for 'cn:auth-expired' → clean state logout
    (timers, sessionService, storage.clearAuth, all auth state),
    toast "Your session has expired — please sign in again.",
    navigate('/login'). No API signout call (token already dead).
