─── WHAT IS LIVE (023) ─────────────────────────────
 jtd_plan(tenant, is_live, {from, to (≤120 d), lanes[], who, q}, user)
   jtd_ops_board regrouped by IST anchor day. Every day of the window, empty
   days included, each with its cards (the board's own rows → the same
   JobCard, the same verbs) and counts: to_place · proposed · asked ·
   to_confirm · confirmed · in_progress · unassigned_services · payments ·
   followups · reminders_due · declarations · needs_you. `carried` = rows
   anchored before the window (overdue), `parked` = no anchor. Passes through
   team, ladder, ask_channels; returns vani_enabled.
 jtd_plan_day(tenant, day, actor…)   "Plan this day"  — VaNi leverage
   Every service on the day with no slot gets one: 10:00 IST first, then
   +2 h per service already placed for the same technician (unassigned
   share one sequence; nobody is guessed a technician). Each is
   jtd_schedule_visit(proposed) — never confirmed. If the day is today and
   the hour has passed, starts at the next full hour. Idempotent.
 jtd_ask_day(tenant, day, channel, actor…)   "Ask everyone" — VaNi leverage
   Every proposed-not-asked slot on the day → jtd_ask_visit_slot(email |
   whatsapp). Until the slot-request templates are registered every row
   refuses no_template; the UI only offers channels in ask_channels, so the
   button does not appear yet.
 Both refuse `vani_off` when vani_is_enabled(tenant) is false. The single-
 item verbs on the cards are not gated.

─── API ────────────────────────────────────────────
 GET  /api/jtd/collections/plan?from&to&lanes&who&q
 POST /api/jtd/collections/plan/:day/place            → jtd_plan_day
 POST /api/jtd/collections/plan/:day/ask {channel}    → jtd_ask_day
 vani_off → 403 · day_passed / day_required / bad_channel → 400.

─── UI ─────────────────────────────────────────────
 /ops/services → new PLAN tab (between Commitments and Activity; revenue
 side only). Window Next 7 / 14 / 30 d or dates; lane All · Collections ·
 Services; Who (whole team / mine / unassigned); search. A summary line for

 Under it the day's cards — the board's JobCard, compact, first 6 then
 "Show all N" — with the SAME actions wiring as Ops (nudge, call, assign,
 pause/resume, confirm declaration, invoices, assign/schedule/confirm/start/
 complete/ask visit), the Log-a-call sheet and the History drawer.
 "Carried over" (overdue, collapsed, red) sits first; "Parked" (no date)
 last. The page header's Refresh button and progress bar follow the plan.
 A STATUS select (owner ask, 2026-09-18): Need you · To place · Slot

 Payments due · Reminders due · Declared · Follow-ups, with the window's
