FEATURE: payment-gated-plan-topup
═══════════════════════════════════════════════════════════════════

WHAT THIS IS
────────────────────────────────────────────
Plan subscribe/switch and pack purchase now collect real Razorpay
payment before entitlements (contract limits, notification credits,
Extend addon flags) are granted. Previously every plan/pack activated
and granted its full entitlement instantly, with zero payment ever
collected — a paid plan like Yearly (INR 19,999) was effectively free.

Also adds the Website/WhatsApp Extend touchpoint packs and fixes the
Quarterly plan's duration.

SUBMODULES AFFECTED
────────────────────────────────────────────
  - contractnest-edge (edge function + migration file, source-of-record
    only — the DB functions and edge function are ALREADY LIVE on
    Supabase; you do not need to run the migration or redeploy)
  - contractnest-ui   (Razorpay checkout wiring, pack flag rendering)
  - contractnest-api  (response type updates only, no runtime behavior)

IMPORTANT — DB/EDGE ALREADY LIVE
