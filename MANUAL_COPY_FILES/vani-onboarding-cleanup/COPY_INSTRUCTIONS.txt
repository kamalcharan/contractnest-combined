----------------------------------------------------------------
ROOT CAUSES FIXED
----------------------------------------------------------------
1. /onboarding redirected on its first render, before the saved status
   arrived; the hook's default (step 1 = legacy "welcome") read as "not
   started" → /start. It now waits, with a loader.
2. Even loaded, it mapped the numeric current_step counter onto the LEGACY
   11-step list. It now resumes from completed_steps in VaNi order for the
   tenant's persona (journey.ts resumePathFor), and passes the persona in
   route state (Terms / Payments / Assets / Done read it).
3. Steps that were never recorded:
   · "Your terms" — the API rejected 'terms-conditions' (not in its list)
   · skipping "Your assets" sent nothing
   · First contract and Your plan both wrote 'done', overwriting Workspace
     ready's data → now 'first-contract' and 'plan-selection'
