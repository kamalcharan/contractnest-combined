WHAT WAS FOUND (root cause)
------------------------------
Investigated why Contacts showed "Dr. Pavan Kulkarni" but Group Sessions
showed "Pavan Kulkarni" with no title. Turned out to be much bigger than
that one screen. Salutation had:

  - FIVE independent definitions of "what are the valid options" across
    the codebase (one live with 23 importers, two dead duplicates, two
    more inline hardcoded arrays in Create-mode's Edit tab and a wizard
    review step) — with THREE DIFFERENT VALUE ENCODINGS for the exact
    same real-world choice: lowercase codes ('mr'), bare capitalized
    words ('Mr'), and capitalized-with-period ('Mr.').

  - SIX independent re-implementations of "how do we turn salutation +
    name into a display string" — of which TWO were genuinely broken,
    not just duplicated: contactService.ts and pages/contacts/view.tsx
    both did `${contact.salutation}. ${name}` with NO label lookup at
    all, so a record saved as 'mr' rendered as "mr. Pavan Kulkarni" —
    lowercase, wrong case, on two real screens.

  - Live production data already reflected this: t_contacts.salutation
    held null (282 rows), 'mr', 'Mr.', 'mrs', 'Ms.', 'Dr', 'Dr.' — six
    distinct stored strings for what should be five clean codes, on a
    column with NO database constraint of any kind (plain varchar).

        file. Writes the same lowercase codes Create mode writes.
      - Also fixed the READ-ONLY display, which was printing the raw
        stored code (e.g. "mr") instead of its label ("Mr.") — now
        looks it up properly.

  components/contacts/forms/ContactPersonsSection.tsx
      - Its own dropdown (for a corporate contact's "people") had the
        same blank-option / no-forcing gap as old Create mode — fixed
        the same way, same DEFAULT_SALUTATION.
      - getPersonDisplayName() already did a correct lookup (this one
        wasn't broken), but reimplemented it inline. Now calls
        formatContactDisplayName() with a synthesized {type:'individual'}

        Kept its own "New Contact Person" placeholder for a still-blank
