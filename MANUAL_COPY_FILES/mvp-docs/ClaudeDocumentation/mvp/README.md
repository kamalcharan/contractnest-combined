## The one-paragraph version

Build the product-led shell you already designed — don't redesign it. In five signed-off
sprints, add only what doesn't exist: onboarding, an express contract lane, and
hide-until-earned rules. UX-only: no new API, edge function, table or column, so BBB is
structurally safe. First real users are BBB chapters #2 and #3, because each chapter is
its own tenant and the 39-chapter rollout is the same work as this build. Success is
chapter #4 onboarding in under 30 minutes of founder time.
