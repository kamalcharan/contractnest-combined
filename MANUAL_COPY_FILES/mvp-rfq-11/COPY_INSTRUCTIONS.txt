WHAT CHANGED — the "Type" step (nomenclature)
Now uses the SAME grouped design as the contract wizard's "What type of contract
is this?" step:
  • Category group headers (icon + label + "N types"), e.g. "Equipment
    Maintenance Contracts · 6 types", "Facility & Property Contracts · 3 types".
  • Cards with the short code (AMC, CMC, PMC …) + full name + a radio/check,
    matching the wizard.
And it MAPS to what the buyer picked in step 1:
  • Equipment → equipment-based types  · Facility → entity-based types  ·
    Service → service-based types (via form_settings flags). Falls back to all
    types if nothing matches, so it never blocks.
Picking a type still auto-fills the typical duration.
