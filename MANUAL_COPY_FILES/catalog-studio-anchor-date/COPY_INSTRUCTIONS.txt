MANUAL COPY INSTRUCTIONS - catalog-studio-anchor-date
===============================================================

FEATURE: Catalog Studio block wizard gains an optional "First
occurrence date" field for cyclical/Group Session blocks. When set,
gs_generate_schedule uses that exact date as the series' first
occurrence instead of always computing "next occurrence of the
weekday anchor on/after the earliest contract start date" — which is
what produced BBB's Saturday Cadence mismatch (the real chapter's
first meeting didn't land on the auto-computed date).

Also fixes a pre-existing gap found while building this: the
"Repeat on a fixed weekday?" dropdown set a wizard field
(cycleAnchorWeekday) that buildConfig() never actually read — so
picking a weekday when creating a NEW block silently didn't save it.
Only blocks whose serviceCycles config already existed (e.g. from a
template import) carried an anchorWeekday through. Fixed alongside
the new date field since both go through the same wiring.
