WHAT THIS BUNDLE DOES
─────────────────────
Collapses per-tenant notification-type toggles onto the existing VaNi
rules system (t_vani_rules / m_vani_rule_templates) instead of the
parallel n_jtd_tenant_source_config table. Tenants now see and control
message-type toggles from Settings → Automation Rules → Notifications.
